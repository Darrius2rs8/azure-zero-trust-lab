# Azure Zero Trust Lab

## Overview

This repository documents my hands-on cloud security lab built to simulate an enterprise Microsoft Azure environment. The purpose of this project is to strengthen my skills in Microsoft Entra ID, Azure administration, identity and access management (IAM), Zero Trust architecture, Microsoft Intune, Microsoft Defender, and PowerShell automation.

As an IT Help Desk Analyst transitioning into Cloud Security Engineering, this lab demonstrates practical experience configuring and securing cloud environments using Microsoft technologies.

---

## Objectives

- Build a secure enterprise Azure environment
- Implement Zero Trust security principles
- Configure Microsoft Entra ID identities and groups
- Deploy Conditional Access and Multi-Factor Authentication (MFA)
- Manage devices with Microsoft Intune
- Implement Role-Based Access Control (RBAC)
- Automate administrative tasks using PowerShell
- Simulate security incidents and document investigations
- Build a portfolio demonstrating real-world cloud security skills
